# Changelog

All notable changes to open-alive. This project follows [Semantic Versioning](https://semver.org/).

## 0.1.0 — Unreleased

First public release as **open-alive**.

- Real-time dashboard, pixel office, event stream, token usage and embedded terminal for Claude Code sessions
- Ticket runner (local / SSH) with verification, decisions and optional auto-commit
- Optional orchestration through any OpenAI-compatible gateway, with a user-owned model catalogue (`~/.open-alive/models.json`)
- `open-alive setup` wizard and `scripts/install.sh` one-shot installer
- Token-authenticated remote access (off by default)
- Prompt coach and Efficio self-evaluation
