# Code of Conduct / 행동 강령

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
이 프로젝트는 [Contributor Covenant 2.1](https://www.contributor-covenant.org/ko/version/2/1/code_of_conduct/)을 따릅니다.

## In short / 요약

- Be respectful and inclusive. Harassment, personal attacks, and discriminatory language are not tolerated.
  서로 존중하고 포용합니다. 괴롭힘·인신공격·차별적 표현은 허용되지 않습니다.
- Critique ideas, not people. / 사람이 아닌 아이디어를 비판합니다.
- Assume good faith and help newcomers. / 선의를 전제하고 처음 온 사람을 돕습니다.

## Enforcement / 적용

Report unacceptable behaviour privately to the maintainers through the contact listed on the
repository profile (or GitHub's private reporting). Reports are handled confidentially, and
maintainers may remove content or ban participants who violate this code.

부적절한 행동은 저장소 프로필에 표시된 메인테이너 연락처(또는 GitHub 비공개 신고)로 알려주세요.
신고는 비밀이 보장되며, 메인테이너는 위반 콘텐츠를 삭제하거나 참여를 제한할 수 있습니다.
